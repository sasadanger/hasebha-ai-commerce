# Olist Phase 2B Development-Only Sensitivity Protocol

Phase 2B compares the nine-feature Strict Core with an explicitly authorized retrospective Contract B upper bound on identical rolling temporal folds ending before 2018-05-01. It has no final-Test route and cannot replace the locked Phase 2A champion.

Repository evidence confirms no Contract B feature as immutable at approval. Consequently, the primary as-of-compatible expanded whitelist is empty. Payment, item/value, and product-property aggregates are evaluated only as **Retrospective expanded-feature sensitivity with unverified as-of semantics**. Location and historical outcome aggregates are excluded because snapshot, privacy, or event-time safety is not established sufficiently for this implementation.

All transformations fit within each training fold. Average Precision is canonical. Paired row bootstrap uses 1,000 resamples and seed 42; it may understate temporal dependence. Any thresholds are development-selected research thresholds, not operational optima.
